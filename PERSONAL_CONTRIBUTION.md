# Personal Contribution - Zichuan Wang

## Role Overview

I worked on Provision It as a front-end developer in Group 12. My contribution also extended to database schema design, deployment, Windows setup support, final-presentation preparation, and team coordination.

## Front-End Development

- Designed two alternative interface directions for the client to review.
- Prototyped interface ideas in Figma and implemented the selected direction with HTML, CSS, and JavaScript.
- Improved the interface iteratively by testing its usability and comparing its layout and interaction patterns with established web applications.
- Collaborated with the wider team to keep the front end aligned with the Flask API and PostgreSQL-backed application.

## Database Schema Design

- Contributed an initial conceptual database design and participated in discussions that shaped the final schema.
- Proposed reducing redundant fraction records when fractions share the same owner, unit price, and other relevant attributes. Equivalent fractions can be represented together while the system still preserves their quantity and ownership meaning.
- Helped the team reason about storage efficiency, ownership history, and the relationship between assets, fractions, users, and transactions.

## Deployment and Local Setup

- Independently learned Render and deployed a working version of the application, going beyond the original requirement to provide only a deployment plan.
- Contributed to the deployment documentation so that the application could be reproduced and maintained by others.
- Helped repair and improve `setup_env.bat`, making local setup more reliable for Windows users.

## Presentation and Teamwork

- Created the final presentation in Canva, focusing on a clear structure, accessible explanations, and an engaging delivery.
- Participated actively in team meetings, technical discussions, and collaborative problem-solving.
- Supported teammates when issues arose and communicated across different technical backgrounds.
- Completed assigned Kanban tasks on time and used remaining time for further refinement where possible.
